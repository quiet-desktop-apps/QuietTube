# Security

This is an early-stage, community-maintained project. There is no security audit,
service-level commitment or supported LTS branch. Security fixes target the latest
`master`; update your checkout and dependencies as documented.

Report vulnerabilities privately through this repository's **Security → Report a
vulnerability** page. If the button is unavailable, ask the maintainer to enable
private reporting without describing the vulnerability publicly. Do not open a
public issue containing exploit details, credentials, cookies, QR codes, private
messages, account databases, authentication logs or signed media URLs.

Describe affected versions, prerequisites, impact and a minimal reproduction using
synthetic data. There is no promised response deadline or bug bounty.

Authentication/session data is sensitive even when file permissions restrict it.
Do not assume local files are encrypted. See the app's architecture and user guide
for storage and service limitations. Do not use this project for cases requiring
formal security assurances.
